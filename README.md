# Netflix Top 10 Weekly Dataset 분석

넷플릭스 글로벌·국가별 주간 Top 10 데이터(2021-07-04 ~ 2026-11-15, **281주**)로
"작품은 어디서 데뷔해야 글로벌로 퍼지는가"를 분석하고, 데뷔 초기 발자국만으로 확산을 예측하는
모델과 의사결정용 시뮬레이터까지 만든 종합 프로젝트입니다.

- 분석 단위: 94개국(러시아 2022.3 이후 제외) · 고유 작품 12,486편 · 글로벌 히트 3,585편(28.7%)
- 산출물: 재현 스크립트 17개 · 노트북 3개 · LightGBM 예측 모델 · Streamlit 대시보드 · 9페이지 보고서
- 핵심 스토리: **파나마에서 발견한 '미러' 이상 신호 → 글로벌 순위의 시장 편향 분리 → 시장 파워 재정의**

## 데이터 개요

| 파일 | 설명 |
|---|---|
| `data/raw/all-weeks-global.csv` | 글로벌 주간 Top 10, 2021-07-04 ~ 2022-01-16 (구형 CSV, 시청시간 포함) |
| `data/raw/all-weeks-countries.csv` | 94개국 주간 Top 10, 같은 기간 (구형 CSV) |
| `data/raw/*_2026-11-11.tsv` | 위 두 파일의 공식 최신 갱신분(탭 구분) — 결합해 281주 완성 |

- `all-weeks-countries.csv`는 **cp1252 인코딩** — `pd.read_csv(..., encoding="cp1252")`로 읽어야 합니다.
- 신형 TSV와 결합·검증 절차는 `scripts/14_raw_data_combine.py`(주차 281·국가 94·작품 12,486 하드 검증)와
  `scripts/15_netflix_data_refresh.py`를 따릅니다.
- 장르는 IMDb 태그에 JustWatch(한국 공식 제목 DB)를 보완해 **커버 99.7%**(미확보 43편은 결측 피처로 처리).

## 핵심 발견 (상세: reports/보고서.pdf · app/streamlit_app.py "인사이트" 탭)

1. **미러(파나마 이상 신호)** — 파나마의 글로벌 파워가 인구 대비 6배대로 튀는 현상의 원인은
   파나마 자체가 아니라 **미국과 1~2위를 교대로 반복하는 '미러' 작품군**. 글로벌 순위에는
   대형 시장의 이중 반영이 섞여 있다 → 시장 파워는 "글로벌 획득"과 "국내 유지"로 분리해 측정.
2. **시장 파워 이동** — 파워 상위국과 그 추세의 연도별 변화(2021H2~2026H1 기간별 재추정).
3. **언어 장벽은 장르마다 다르다** — 영어 출신 1,734편 / 비영어 출신 1,824편 비교에서
   비영어 작품도 코미디·로맨스(통과율 15~16%)를 제외하면 벽이 낮다. 언어보다 장르가 관문.
4. **초기 신호** — 데뷔 첫 주 어느 나라에서 어느 장르로 차트에 오르는가가 확산을 예측한다
   (아래 모델). 실무 적용: 신작은 미국 단독 공개 대신 아시아 허브 동시 공개가 확률을 크게 올림
   (한국 원작 기준 27.3% → 76.9%).

## 모델링 요약

탐색 모델(노트북 3.0) → 최종 모델(시간 분할 + LightGBM)의 두 단계.

| 모델 | 질문 | 핵심 성능 (out-of-sample) |
|---|---|---|
| B 취향 지도 | 취향이 비슷한 나라끼리 묶이나? | 3개 취향 블록(서양+중동+아프리카 / 동·남아시아 / 라틴), 확산 후보 51건 |
| C 시장 편향 | 어떤 시장이 글로벌 순위를 좌우하나? | AUC 0.929 — 미국·브라질 계수 최상위 (파나마 미러 발견의 출발점) |
| A 확산 예측 | 초기 발자국만으로 미래를 예측할 수 있나? | 글로벌 히트 AUC 0.871(1주차)~0.905(4주차) |
| A' 회귀 | 몇 개국까지 퍼질까? | MAE 2.5개국, R² 0.898 (4주차 발자국) |

**최종 모델 (`models/model_v2_lgbm.joblib`)**

- LightGBM 43피처(데뷔 발자국 + 장르·언어·인구·밀도) + Isotonic 확률 보정
- 검증: 무작위 분할 금지 — **학습 2021-07~2026-03 완결작 9,936편 / 테스트 2026-03-15~11-15 신작 1,443편**
- 발전: 기준선 v2(41피처, AUC 0.936) → v2.1(언어 피처) → **v2.2(밀도 피처, 4주차 AUC 0.951·정밀도 0.869, 1주차 0.918/0.850)**
- 회귀: 최종 진입 국가 수 오차 ±2.8(4주차) / ±5.0(1주차)개국
- 확률 보정: 원시 확률은 부풀려진다(예: 3개국 진입 56.9% → 보정 27.3%) — 보정 확률만
  의사결정에 사용 (`scripts/11_calibration_check.py`)
- 검증 스크립트: 시간 분할(`model_35week_results.csv`)·보정(`calibration_results.csv`)·
  번들 재현(`17_model_bundle_verify.py`)

## 한계

1. 순위 데이터는 시청 시간의 세분량을 담지 않아 파워 추정은 순위 패턴 기반 구조적 추정.
2. 장르 태그의 주관성과 일부 오매칭 가능성, 언어는 차트 카테고리 기준이라 더빙·다국어 분류에 경계.
3. 상관관계와 인과관계는 구분 — 진입/확산이 글로벌 히트를 유발한다는 인과 증명이 아니라 경향성.
4. Top 10 밖(미진입)은 미관측이고, 관측 말기 데뷔작은 관측이 잘린다(완결작만 학습으로 완화).
5. "글로벌 히트" 정의 자체에 대형 시장 편향이 있다(모델 C가 입증 — 이 프로젝트의 출발점).
